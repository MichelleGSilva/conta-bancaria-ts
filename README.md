# Sistema de Conta Bancária (conta-bancaria-ts)

> Projeto desenvolvido para prática de TypeScript durante o Bloco 01 do Bootcamp de Desenvolvimento Full-Stack em JavaScript da Generation Brasil.

## 🧐 Sobre o projeto

Este é um sistema de conta bancária simples, construído com **TypeScript** e Node.js. A aplicação roda no terminal (console) e simula operações bancárias típicas, como depositar, sacar, consultar saldo e extrato.

O foco é ensinar e praticar conceitos centrais de programação orientada a objetos, manipulação de dados e interatividade via terminal.

## 🎯 Principais objetivos

- Criar um sistema bancário básico com operações como depósito, saque, transferência e consulta de saldo; 
- Utilizar orientação a objetos para modelar clientes e contas;
- Trabalhar com TypeScript para reforçar tipagem estática, classes e herança;
- Praticar entrada de dados pelo terminal e lógica de fluxo;
- Desenvolver habilidades de teste manual e manuseio de erros.

## 💻 Tecnologias utilizadas

- **TypeScript** — para tipagem forte e OOP  
- **Node.js** — para execução da aplicação no backend  
- **readline-sync** — para leitura interativa de inputs no terminal  
- **ts-node**
